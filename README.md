# mango-ch3-fret-modelling

Analysis code for Chapter 3 of the PhD thesis "Fluorogenic RNA Mango Aptamers: Single-Molecule Characterisation and Applications in CRISPR-Mediated Genomic Imaging" (Fangqi Liu, Imperial College London, 2026).

## Scope
- Building the RNA Mango helical-ruler FRET constructs
- Orientation-dependent FRET model fitting (Cy5 acceptor)
