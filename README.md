# mango-ch3-fret-modelling

Analysis code for Chapter 3 of the PhD thesis "Fluorogenic RNA Mango Aptamers: Single-Molecule Characterisation and Applications in CRISPR-Mediated Genomic Imaging" (Fangqi Liu, Imperial College London, 2026).

## Scope
1. Coordinate extraction: DSSR-based extraction of nucleotide coordinates from PDB structure files
2. System assembly: combining the Mango aptamer, RNA helix and Cy5 coordinates into a single model system
3. FRET modelling: orientation-dependent FRET model fitting

## Requirements
DSSR is not distributed in this repository. Obtain it separately under its own licence.
